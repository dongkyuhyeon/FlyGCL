# MISA 원본 코드 보관함

이 폴더는 [MISA 공식 저장소](https://github.com/kangzhiq/MISA)의 코드 보관과 FlyGCL 통합 작업을 분리하기 위한 공간입니다.

- **원본 전체 텍스트 소스:** [MISA/](./MISA/)
- **원본 출처·커밋·제외 자산:** [SOURCE_MANIFEST.md](./SOURCE_MANIFEST.md)
- **FlyGCL 코드 차이 분석:** [../notes/MISA_vs_FlyGCL.md](../notes/MISA_vs_FlyGCL.md)

**중요:** `MISA/` 하위 소스 파일은 원본에서 수정하지 않고 가져온 스냅샷입니다. 바이너리 Prompt 체크포인트와 이미지 파일은 여기에 복사하지 않았으며, 원본 경로를 MANIFEST에 기록했습니다.

현재는 1단계(원본 코드 확보 및 비교 분석)만 수행했습니다. 원본 코드를 FlyGCL 실행 코드로 등록하거나 학습/평가를 실행하지 않았습니다.

MISA 공식 저장소의 LICENSE(MIT)가 원본 코드 내부에 그대로 포함되어 있습니다.
